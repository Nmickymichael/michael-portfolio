# Michael Harrison Muthee Muriithi — Personal Portfolio

A modern, responsive personal portfolio website showcasing my ICT background, technical skills, professional experience, leadership and software development work.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Features
- Responsive layout for desktop, tablet and mobile
- Interactive light and dark themes
- Mobile navigation
- About, skills, projects, experience, education and contact sections
- Links to GitHub profile and featured ClassTrack project
- No framework, build step or paid dependency required

## Run locally
Open `index.html` in a browser. The site is a static website and does not require a package installation or build command.

## Deploy with Netlify
1. Sign in to Netlify.
2. Choose **Add new project** → **Import an existing project**.
3. Connect GitHub and select `Nmickymichael/michael-portfolio`.
4. Leave the build command empty.
5. Set the publish directory to `.` (the repository root).
6. Deploy the site.

Netlify can automatically redeploy the site whenever changes are pushed to the GitHub repository.

## Before publishing
- Replace `YOUR_EMAIL_ADDRESS` in `index.html` with the professional email address you want displayed.
- Review all dates, experience descriptions and project links for accuracy.
- Add a professional photograph later if desired.
