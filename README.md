# Mickoryn — Developer Portfolio

A modern, responsive portfolio website showcasing software development projects, technical skills and selected work under the Mickoryn developer identity.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Features
- Responsive layout for desktop, tablet and mobile
- Interactive light and dark themes
- Mobile navigation
- About, skills, projects, experience, education and contact sections
- Links to GitHub profile and featured projects
- No framework, build step or paid dependency required

## Run locally
Open `index.html` in a browser. The site is a static website and does not require a package installation or build command.

## Deploy with Netlify
1. Sign in to Netlify.
2. Choose **Add new project** → **Import an existing project**.
3. Connect GitHub and select this repository.
4. Leave the build command empty.
5. Set the publish directory to `.` (the repository root).
6. Deploy the site.

Netlify can automatically redeploy the site whenever changes are pushed to the GitHub repository.

## Before publishing
- Review contact links and public profile details before deployment.
- Review project descriptions and links for accuracy.
